Reproductibilité et traçabilité
===============================

Principes
------------

Les hypothèses, règles de calcul et choix de modélisation sont explicités afin
de permettre la compréhension et la vérification des résultats.

Environnement technique
---------------------------

- Base de données : PostgreSQL  
- Scripts : SQL 
- Versioning : Git  
- Documentation : reStructuredText, Sphinx
- Hébergement : GitHub

Limites
-----------

Les scripts et schémas présentés relèvent d'un travail de prototypage et ne
constituent pas une version opérationnelle de l'outil.
