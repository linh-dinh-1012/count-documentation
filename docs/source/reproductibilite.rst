Reproductibilité et traçabilité
===============================

🇫🇷 Principes
------------

La reproductibilité est un principe central de COUNT.
Les hypothèses, règles de calcul et choix de modélisation sont explicités afin
de permettre la compréhension et la vérification des résultats.

🇬🇧 Principles
-------------

Reproducibility is a core principle of COUNT.

🇫🇷 Environnement technique
---------------------------

- Base de données : PostgreSQL  
- Scripts : SQL (tests et prototypage)  
- Versioning : Git  

🇬🇧 Technical environment
-------------------------

PostgreSQL, SQL scripts and Git version control support reproducibility.

---

🇫🇷 Limites
-----------

Les scripts et schémas présentés relèvent d'un travail de prototypage et ne
constituent pas une version opérationnelle de l'outil.

🇬🇧 Limitations
---------------

Scripts and schemas are intended for prototyping purposes only.
They do not represent an operational version of the tool.
