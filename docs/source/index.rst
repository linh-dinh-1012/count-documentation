COUNT - Documentation technique
===============================

COUNT est un outil de calcul d'impact écologique dédié aux salles de cinéma.
Cette documentation présente l'architecture des données, les workflows de
traitement et les principes de reproductibilité du projet.

Le projet est actuellement à l'état de prototype conceptuel.

Cette documentation correspond à un travail de contribution technique et de
formalisation, réalisé en appui au projet COUNT porté par l'Association pour
la transition bas carbone (ABC).
